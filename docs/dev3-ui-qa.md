# ผลเก็บงาน UI/UX ของ Developer 3

ตรวจวันที่ 19 พฤศจิกายน 2026 ตาม `Design.md`: ภาษาอังกฤษ, Dark/Sci-Fi, Kantumruy Pro และ MarketplaceIcon ชุดเดิม

## สิ่งที่ปรับแล้ว

- เมนู Staff console ระบุหน้าปัจจุบันด้วยข้อความ สี และขอบ; บนมือถือแสดงเมนูเป็นกริดที่แตะได้สะดวก
- Review queue มีสรุปจากข้อมูลจริง แท็บและการค้นหาภายในคิว สถานะไม่มีรายการ/ค้นหาไม่พบ และปุ่ม Refresh
- Order review แยกเหตุผล หลักฐาน ข้อตกลง แชท timeline และแผงตัดสิน พร้อมลิงก์ข้ามส่วนบนมือถือ
- คำตัดสินมีขั้นทบทวนก่อนเรียก API/เปิด MetaMask ย้อนกลับไปแก้ได้โดยตัวเลือกและเหตุผลไม่หาย มีข้อความตรวจข้อมูลและโฟกัสไปยังช่องที่ต้องแก้
- หลักฐานมีสถานะกำลังเปิด/ตรวจ hash แยกแต่ละไฟล์ ซ่อนรายละเอียด hash ใน disclosure และขอลิงก์ใหม่เมื่อรูปโหลดไม่ได้
- Staff history ค้นหากิจกรรม ผู้ดูแล Wallet และ order ID ได้
- Super Admin แยกสถานะที่ยืนยันแล้ว/ข้อมูลเก่า/ยืนยันไม่ได้ พร้อมเทียบ role บนเว็บกับ contract
- เพิ่ม loading skeleton และ error fallback ที่ใช้ `retry()` ตามคู่มือ Next.js 16.4.6 ที่ติดตั้ง
- ปรับ semantic tokens สำหรับสถานะ และบันทึกส่วน Staff console เพิ่มใน `Design.md`

## ตรวจด้วยเบราว์เซอร์

ใช้ component จริงกับ fixture ใน `.runtime/admin-ui-preview/` ซึ่งแยกจากฐานข้อมูล ไม่มีการเพิ่มออเดอร์หรือเปลี่ยนบทบาทในฐานข้อมูล และไม่มีการส่งธุรกรรม

| การตรวจ | ผล |
| --- | --- |
| Queue / Order / History / Super Admin × 320, 375, 768, 900, 1440px × Dark/Sci-Fi | ผ่าน 40 ชุด ไม่มี overflow แนวนอน และไม่มีปุ่ม/แท็บถูกตัดขอบ |
| Queue search และ clear search | กรองรายการและคืนข้อมูลเดิมได้ |
| เปลี่ยนแท็บคิวผ่าน ArrowRight | เปลี่ยน active tab ได้ |
| คิวว่างบนมือถือ | แสดงคำแนะนำ เมนูและแท็บอยู่ครบ |
| ฟอร์มไม่มีผลตัดสิน | แสดง error และย้าย focus ไปตัวเลือก |
| ทบทวน refund/release บน desktop/mobile | แสดงผลตัดสินและเหตุผลก่อนเปิด MetaMask |
| กลับจากทบทวนไปแก้ไข | ตัวเลือกและเหตุผลยังอยู่ |
| เปิดหลักฐาน / ตรวจ hash / ไฟล์ไม่พร้อมใช้งาน | แสดงรูป ผล hash และ error ตามไฟล์ |
| เปิดแล้ว Cancel การพักฝากเงิน | กลับสู่ปุ่มเดิมโดยไม่ส่งธุรกรรม |
| ค้นหา staff history | เหลือเฉพาะกิจกรรมที่ตรงกับผู้ดูแล |
| หน้า `/admin` บน dev server จริงโดยไม่มี session | แสดงหน้า Go to Wallet และยังตรวจสิทธิ์ตามเดิม |
| Console ของ preview และหน้า access จริง | ไม่พบ error ระหว่างกรณีที่ตรวจ |

## ตรวจโค้ด

- `npm run typecheck`: ผ่าน
- `npm test`: ผ่าน 12 tests
- `git diff --check`: ผ่าน

## ขอบเขตที่ยังต้องตรวจแยก

นี่เป็นผลตรวจ UI ไม่ใช่รายงานตรวจรับ Dev 3 ทั้งระบบ ยังไม่ยืนยันเส้นทาง signer → MetaMask → Sepolia → indexer ด้วย session หลายบทบาท ไม่ได้ส่งเงินจริง/ธุรกรรมทดสอบ และไม่ได้ติดตั้ง Cron ในรอบนี้

หน้าที่มีข้อมูลทดสอบด้วย fixture เนื่องจาก local ไม่มีออเดอร์สำหรับตรวจภาพ การตรวจด้วย session และข้อมูลจริง รวมถึง RPC outage, audit retry และการเชื่อม Dev 2 ยังอยู่ใน `dev3-checklist.md` ไม่ได้ใช้การผ่านภาพหน้าจอแทนการทดสอบระบบเหล่านั้น
