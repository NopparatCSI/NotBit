# คู่มือผู้ซื้อ ผู้ขาย และผู้ดูแล NOTBIT

ใช้ Sepolia เท่านั้น ชื่อปุ่มอิง UI ภาษาอังกฤษตาม `Design.md` ข้อมูล Wallet และ Contract สำหรับเว็บออนไลน์ดูใน [สถานะส่งมอบ](priority-24-29.md)

## ผู้ซื้อ

1. เปิด Wallet → Sign in with MetaMask เลือกบัญชีผู้ซื้อและ Sepolia แล้วลงนามข้อความยืนยันตัวตน
2. เลือกสินค้า → Chat with seller ตกลงรายละเอียดในแชท ตรวจชื่อตัวละคร เซิร์ฟเวอร์ จำนวน และเวลานัดหมาย ชื่อตัวละครยังไม่ได้ยืนยันกับระบบเกม
3. เปิด Deal summary ตรวจ signed offer, ยอดฝาก และค่าบริการ กด Deposit แล้วตรวจรายละเอียดใน MetaMask ก่อนยืนยัน
4. รออย่างน้อย 3 confirmations และรอระบบซิงก์ออเดอร์ ไม่ฝากซ้ำระหว่างรอ สามารถรีโหลดแล้วติดตามธุรกรรมเดิมได้
5. หลังผู้ขายยืนยันส่ง เปิด Evidence อัปโหลดภาพการรับสินค้า ตรวจภาพแล้วเลือกยืนยันว่าได้รับจริงก่อน Confirm receipt การยืนยันทำให้จ่าย 95% ให้ผู้ขายและ 5% ให้แพลตฟอร์ม
6. หากเกิดปัญหาก่อนออเดอร์ปิด ให้กรอกเหตุผลและหลักฐาน เปิดข้อพิพาท แล้วตรวจสถานะ IN_REVIEW เงินจะอยู่ใน escrow จนผู้ดูแลตัดสิน

## ผู้ขาย

1. ใช้ Wallet ที่ต่างจากผู้ซื้อ เข้า Sell แล้วกรอกรายละเอียด ราคาเป็น Sepolia ETH และรูปประกาศที่เหมาะสม
2. ในห้องแชท เปิด Deal summary → Create offer ตรวจเงื่อนไข → Review offer → Sign and send offer ข้อเสนอหมดอายุใน 30 นาที
3. ส่งสินค้าเมื่อเงินฝากยืนยันและระบบซิงก์แล้ว เก็บภาพที่สื่อถึงออเดอร์นั้น อัปโหลดใน Evidence แล้ว Confirm delivery ภายใน 24 ชั่วโมงหลังฝาก
4. ผู้ซื้อมีเวลา 48 ชั่วโมงหลังยืนยันส่งเพื่อยืนยันรับหรือเปิดข้อพิพาท ถ้าหมดเวลา ออเดอร์จะเข้าตรวจและไม่มีการจ่ายหรือคืนอัตโนมัติ

## Admin และ Super Admin

- เปิด `/admin` ด้วย Wallet ที่ลงทะเบียนและตรงกับบทบาทบน Contract ดูแท็บ In review, Overdue และ Resolved
- เปิดออเดอร์ ตรวจ agreement, รูปหลักฐาน, รูปแชท, ข้อความย้อนหลัง และ timeline การเปิดหลักฐานของ staff มี audit และ signed URL อายุสั้น หากลิงก์หมดอายุให้ขอลิงก์ใหม่
- เลือก Refund buyer หรือ Pay seller per the deal พร้อมเหตุผลเฉพาะเจาะจง กด Review decision ตรวจผลอีกครั้ง แล้ว Confirm in MetaMask
- การตัดสินสำเร็จได้ครั้งเดียว รอ confirmations และ indexer ก่อนถือว่าคู่ค้าเห็นผล หากรีโหลดจะติดตาม hash เดิมต่อ
- เฉพาะ Super Admin หยุด/เปิดเงินฝากใหม่ได้ การหยุดฝากไม่ขวางการจัดการออเดอร์เดิมและการถอนยอดค้างรับ

## ยอดค้างรับและปัญหาทั่วไป

หากผู้รับ ETH ปฏิเสธการโอน Contract จะเก็บยอดไว้ใน pending payout เปิด Wallet → Queued payments ตรวจยอดของ Wallet ตนเองแล้วถอน การถอนสำเร็จลดสิทธิ์ทันทีและถอนได้ครั้งเดียว

| อาการ | วิธีดำเนินการ |
|---|---|
| Account used to sign in ไม่ตรง | เลือกบัญชีเดิมใน MetaMask หรือออกจากระบบแล้วเข้าสู่ระบบด้วยบัญชีที่ต้องการ |
| Network ไม่ตรง | เปลี่ยนเป็น Sepolia และตรวจ chain ID 11155111 |
| Gas ไม่พอ | เติม Sepolia ETH ให้ Wallet ที่ส่งธุรกรรม |
| ถูกปฏิเสธใน Wallet ก่อนมี hash | ตรวจเงื่อนไขแล้วเริ่มใหม่ได้ |
| มี hash แต่ตรวจ RPC ไม่ได้ | เก็บ hash ตรวจ explorer และรอ retry ไม่ส่งซ้ำเพราะ timeout |
| Deposit confirmed แต่รอซิงก์ | รอ scheduler/indexer ไม่ฝากซ้ำ |
| รูปไม่ผ่าน | ใช้ JPEG/PNG/WebP ที่เปิดอ่านได้จริง รูปประกาศ/หลักฐานไม่เกิน 10 MB รูปแชทไม่เกิน 3 MB |
| Upload quota | รอพ้นช่วง 10 นาที; ไม่เปิดหลายคำขอเพื่อข้ามโควตา |

Contract รุ่นนี้เปลี่ยน Admin/Super Admin ไม่ได้ ระบบตั้งบทบาทเต็มรูปแบบเป็นงานรอบถัดไป เมื่อออเดอร์ RELEASED แล้ว การเปิดข้อพิพาทใน Contract นี้ไม่สามารถเรียกเงินกลับได้
